# Prisma Space — mapa de intención de búsqueda

Dominio: https://prismaspace.space/
Idioma inicial: español. Mercado inicial: hispanohablantes; no se atribuyen volúmenes ni posiciones sin datos de Search Console.

## Criterio

- Cada URL responde a una intención distinta: explorar una categoría, completar un flujo de trabajo o aprender un procedimiento.
- Las páginas enlazan a herramientas existentes y aprobadas en `seo/audit.json`; las funciones excluidas por defectos o estado `soon` no se promocionan.
- Las funciones `beta`, `byok` y conectadas declaran sus requisitos; no se prometen usos ilimitados ni resultados garantizados.
- Las consultas son hipótesis editoriales cualitativas. Se priorizarán de nuevo cuando Search Console acumule impresiones y clics.

## Priorización después de publicar

1. Revisar en Search Console qué consultas generan impresiones por URL.
2. Mejorar primero páginas con impresiones y CTR bajo, ajustando título y descripción sin prometer funciones que no existen.
3. Ampliar guías que reciben impresiones pero no clics con ejemplos, capturas propias y aclaraciones de compatibilidad.
4. Consolidar páginas con intención duplicada en lugar de crear variaciones casi idénticas.
5. Revaluar el mapa después de 28–45 días de datos; la indexación y el posicionamiento no están garantizados.

## Observación de SERP

Los resultados revisados muestran que el usuario suele encontrar directorios de herramientas, fichas de operaciones y guías prácticas en verticales como PDF, imagen y transcripción. Prisma adopta esa estructura, pero cada página debe tener contenido y límites propios; no se copian textos ni se inventan cifras de búsqueda.
